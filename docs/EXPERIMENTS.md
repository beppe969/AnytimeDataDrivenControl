# Experiment map and execution order

This package generates the numerical results for the paper
**A Universal Iterated-Logarithm Anytime Law for Data-Driven Control Design**,
by **G. Calafiore**. The table below maps its Section 6 to the numerical scripts
and outputs. `SOURCE_PROVENANCE.json` records the file hashes.

## Paper-to-code map

| Paper location | Scientific computation | Principal source outputs | Reproduction command |
| --- | --- | --- | --- |
| Section 6.1, Table 2 | Scalar roots and deterministic endpoint/crossover sweep | `data/horizon_endpoint_comparison.csv`; `data/horizon_crossover_sweep.csv` | `experiment horizon-comparison` |
| Figure 1 | Plot the deterministic anytime/FH endpoint ratios | `figures/horizon_comparison.{pdf,png}` | `figures` |
| Section 6.2.1, Table 3 | First-target stopping on 10,000 streams | `data/stopping_audit_replicates.csv`; `data/horizon_stopping_replicates.csv` | `experiment stopping-archive`, then `experiment horizon-comparison`, or `full` |
| Section 6.2.2, Table 4 | Continued inspection on a separate 10,000-stream cohort | `data/horizon_monitoring_8000.csv`; `data/horizon_baseline_results.json` | `experiment monitoring`, then `experiment horizon-comparison`, or `full` |
| Section 6.2.3, Figure 2 | Stored-controller availability and recrossing example | `data/archive_audit_replicates.csv`; `data/recrossing_example.csv`; `figures/certificate_archive.{pdf,png}` | `experiment stopping-archive` |
| Section 6.2.4 | Retrospective performance-evaluator sensitivity | `data/lmi_replicates.csv`; `data/selection_sensitivity.csv` | `experiment controller-mpc` |
| Section 6.3, Figure 3 | Empirical hull/box, exact missing mass and tube MPC | `data/disturbance_path.csv`; `data/horizon_disturbance_path.csv`; `data/disturbance_samples.npz`; `checks/horizon_mpc_verification.json` | `experiment controller-mpc`, then `experiment horizon-comparison`, or `full` |
| Section 6.4 | Six-state mechanical instance-level audit | `data/mechanical_results.json`; `data/mechanical_path.csv`; `checks/mechanical_audit.csv` | `experiment mechanical` |

Each selected-study invocation creates its **own** workspace and seeds archived
prerequisite inputs. Two selected-study commands do not automatically chain their
outputs. Use `full` for a completely regenerated, mutually consistent run.
`figures` and `full` additionally export `tables/table2.csv` through `table4.csv`
and matching LaTeX tables, with their values recomputed from the workspace records.

The protocols in [PROTOCOLS.md](PROTOCOLS.md) retain the model definitions
and numerical tolerances. Its `code/`, `data/` and `checks/` paths are relative to
an experiment workspace; the archived equivalents are under `reference/`.
Additional diagnostic seeds remain in their original scripts. No user-supplied
or external dataset is required: all model samples are generated synthetically.

## Complete scientific pipeline

The `full` command runs the scientific scripts in the following order:

```text
certificates.py
verify.py
verify_revision.py
experiments.py
revision_experiments.py
sdp_scale.py
selection_audit.py
monitoring_audit.py
final_figures.py
final_checks.py
horizon_baselines.py
third_review_figures.py
third_review_checks.py
verify_reported_results.py
```

The runner then executes the `export_paper_tables.py` presentation layer and
`compare_reference.py`. A full run starts with empty `data/` and `checks/`
directories. Every dependency used by later scientific scripts is generated by
an earlier step in that same run.

All scientific scripts listed here are included in `code/`. Their filenames are
also used as execution-step labels in the run manifest and logs.

## Important distinctions

The first-target experiment contains fixed-time and stopping-specific comparators
with narrower coverage objectives. The repeated unadjusted CG23 procedure is an
empirical comparator. The FH method uses a cap fixed before sampling, while the
summable and anytime methods admit an unspecified horizon.

FH uses cap 800 in the first-target experiment and cap 8,000 for the independent
continued-inspection experiment. For Table 4, both inspection columns must be
computed from `horizon_monitoring_8000.csv`. `horizon_monitoring_800.csv` records the
short first-target cohort and serves a different purpose.

The deterministic sweep to sample sizes of order 10^12 evaluates certificate
formulas. It does not simulate streams of that length.

The mechanical candidate certificate and the alternative performance evaluator
retain the qualifications stated in `PROTOCOLS.md` and the main README.
