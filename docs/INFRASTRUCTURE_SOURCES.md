# Infrastructure references

The following official resources document the repository metadata and workflow
configuration. They concern the execution infrastructure.

- GitHub citation files: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files
- Citation File Format schema: https://github.com/citation-file-format/citation-file-format/blob/main/schema.json
- Official setup-python action: https://github.com/actions/setup-python/releases/tag/v7.0.0
- Official checkout action: https://github.com/actions/checkout/releases/tag/v7.0.0
- Official upload-artifact action: https://github.com/actions/upload-artifact/releases/tag/v7.0.0
- MIT license text: https://choosealicense.com/licenses/mit/

The v7 release pages for the three GitHub actions were checked on
11 September 2026. Hosted workflow execution remains a separate check from
local numerical validation; see `validation/VALIDATION.md`.
