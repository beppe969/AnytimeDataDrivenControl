# Changelog

## 1.0.1 — 11 September 2026

This package generates the numerical results for the paper
**A Universal Iterated-Logarithm Anytime Law for Data-Driven Control Design**,
by **G. Calafiore**.

The public documentation and run metadata identify the numerical work by its
paper title and author. File-integrity records use repository-relative paths.
Both checksum manifests are included, and the release builder checks that all
required files are present before creating a distributable package.

Scientific algorithms, random seeds and replication counts are unchanged.
The 16 scientific Python files and the reference outputs are preserved exactly.
Local validation of this release is documented in `validation/VALIDATION.md`.
